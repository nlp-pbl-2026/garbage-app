# ごみサポ

名前が分からないごみも、自然な言葉や画像から分別区分を検索できるFlutterアプリです。

自治体の分別資料をTitan Embeddingによる意味検索で検索し、分類・出し方・次回収集日を回答します。判定に必要な情報が足りない場合は、素材などを確認する追加質問を返します。

現在は松山市、八幡浜市、伊予市、伊方町、新居浜市、四国中央市、西予市、東温市、大洲市、砥部町、愛南町、鬼北町、松野町、内子町、松前町、上島町、久万高原町、西条市、今治市、宇和島市の20自治体・706選択地区に対応します。各自治体で分別索引と実日付カレンダーを分離し、公式に確認できた期間だけを案内します（[データ配置ガイド](docs/data.md)）。

バックエンドとFlutterには、自治体別の台帳・分別設定・カレンダーを切り替える共通基盤があります。[東温市の対応範囲](docs/toon-data.md)と、[担当7自治体の接続ガイド](docs/assigned-municipalities-completion.md)に、品目数・公式期間・再生成方法をまとめています。他市町の追加にも専用の公式データ整備と検証が必要です（[Flutterの自治体データ契約](docs/multi-municipality-flutter.md)）。

伊予市は伊予・双海・中山の3 PDFを16地区の実日付に展開し、搬出期限は8時30分です。平岡・鵜崎の5区分は収集日未確認として案内し、通知・iCalを生成しません。新規cloneでは[伊予市のデータ配置](docs/iyo-data.md)も必要です。

伊方町は伊方・瀬戸・三崎の8 PDFを同じ8収集地区群で利用します。発泡スチロールを含む9定期収集区分は当日8時まで。粗大ごみは申込制とし、収集日を推測せず通知・iCalを生成しません。[対応範囲・公式資料の補正・再生成手順](docs/ikata-data.md)を確認してください。公開APIへの反映は別途必要です。

新居浜市は公式辞典1,349行と15種類の2026年度カレンダーに対応します。市街地・大島は7時30分、別子山は9時まで。大型ごみ・自己搬入は定期予定へ含めません。[対応範囲・再生成・検索評価の制限](docs/niihama-data.md)を確認してください。

東温市は重信29・川内3カレンダーと公式辞典1,260行に対応します。水銀式体温計の収集区分は地域別に切り替えます。一部計測器の収集日と重信の一部搬出時刻は未確認として扱い、誤った朝通知を生成しません。2027年4月の製品プラ変更は適用していません。[対応範囲・再生成・検索評価](docs/toon-data.md)を確認してください。

久万高原町は公式辞典2,002行・説明例16行と、久万・美川・面河・柳谷の23選択地区・22カレンダーに対応します。定期収集は朝8時まで。取り外せないリチウムイオン電池内蔵機器や膨張した電池、粗大ごみ等の直接持込を定期収集と区別します。例外ステーション、戸別収集の現行募集、再生成と検索評価の範囲は[久万高原町データガイド](docs/kumakogen-data.md)を確認してください。

西条市は公式分別表1,273行・説明例10行、39選択地区・25カレンダーに対応します。新指定袋と秋祭り休止を反映し、大保木・市之川・加茂の随時収集3区分は日付未確認として案内します。予約制粗大ごみ・拠点回収は定期日程と区別します。[西条市データガイド](docs/saijo-data.md)を確認してください。

上島町は公式ガイドの106品目例と、弓削3・生名2・岩城2・魚島1の8選択地区に対応します。弓削・生名・岩城は地区別収集、魚島は平日7:00～10:00のクリーンセンター持込として扱います。条件付き品目、利用条件、再生成、検索評価は[上島町データガイド](docs/kamijima-data.md)を確認してください。

## 使い方

対応済みのAPIへ接続する場合、Flutter側にはAWS認証やローカルBackendの起動は不要です。[APIからFlutter用データを取得する新規clone手順](docs/frontend-data-setup.md)を整備しています。**全20市町のUI用JSONはAWS公開APIへ反映済みで、Git管理外データの受領なしでセットアップできます。** 資料の利用・再配布条件は未確認のまま別途記録しています。取得方式は元のfrontendを変更せず、隔離コピーで起動・ビルドします。従来の原本生成が必要な場合は[データセットアップ手順](docs/yawatahama-data.md#新規cloneからの取得再生成)を参照してください。

以下の従来コマンドは、必要なFlutterアセットを配置済みの環境向けです。新規cloneでは上記の取得手順を使ってください。

ハッカソン審査用には、審査担当者から共有されたAPI URLを環境変数に設定し、
プロジェクトルートから次を実行してください。ヘルスチェック、Flutter依存関係の
取得、Chromeでの起動をまとめて実行します。

```bash
export GARBAGE_API_BASE_URL='https://<shared-api-endpoint>'
./scripts/run-demo.sh
```

接続先やデバイスを変える場合は、`GARBAGE_API_BASE_URL`、
`GARBAGE_FLUTTER_DEVICE`を指定できます。
APIの疎通だけを確認する場合は`./scripts/run-demo.sh --check`を使います。

個別に起動する場合は、`frontend/` ディレクトリで次を実行してください。

```bash
export GARBAGE_API_BASE_URL='https://<shared-api-endpoint>'
flutter pub get
flutter run -d chrome \
  --dart-define=API_BASE_URL="${GARBAGE_API_BASE_URL}"
```

初期画面ではログインをスキップして利用できます。ローカル認証APIは`SECRET_KEY`（32バイト以上の十分にランダムな値）が必須で、未設定時は認証ルートだけ503になります。固定鍵へのフォールバックはありません。パスワードはUTF-8で72バイト以内です。AWS Lambdaは引き続き認証APIを公開しません。詳しくは[公開リポジトリの安全性と残作業](docs/public-repository-security.md)を参照してください。

今治市は通常地域855行＋説明例12行、関前203行＋説明例11行の独立索引と、233選択地区・44カレンダーに対応します。来島・馬島・小島、鵜島、関前を通常地域と区別し、港の出航時刻が不明な地区に固定の期限を付けません。現行の関前プラスチック・充電池ルール、取得・照合・共有手順は[今治市データガイド](docs/imabari-data.md)を参照してください。AWSへの反映は別作業です。

宇和島市は公式早見表1,124行＋説明例20行、123選択地区・56カレンダーデータ（実日付54パターン）に対応します。118カレンダーPDF（内容33種類）と離島のHTML日程を使い、自治会別資源回収や未確認日を通常収集から分けます。[対応範囲・制限・再現手順](docs/uwajima-data.md)を確認してください。

## 主な機能

- 曖昧な表現からのごみ分類
- テキストのみ・画像のみ・画像とテキストを組み合わせた検索
- 対象地域の分別資料を使ったRAG検索
- 判定に必要な追加質問
- 地区ごとの次回収集日の表示
- 検索結果・確信度などのログ分析

## 検索の仕組み（あいまい検索）

品名が分からない曖昧な入力から正解へ到達するため、検索クエリをTitan Text Embeddings V2でベクトル化し、上位候補を判定LLMへ渡します。

1. **クエリ変換**: Amazon Nova Liteがテキストと任意の画像を読み取り、曖昧な入力を検索向けに言い換える。
2. **意味検索**: Titan Text Embeddings V2でクエリをベクトル化し、Lambda同梱の`item_embeddings.npz`から候補を検索する。松山市以外では、元入力に公式品目名がある場合に限り、同じ自治体のCSVから一致候補も補う。
3. **判定**: Amazon Nova Liteが画像と検索候補から分類を判定し、必要なら追加質問を返す。公式品目と条件が明示される場合は、その行の確認済みの条件で判定を補正する。

検索画像はJPEG・PNG・GIF・WebPのいずれか1枚、3MBまでです。画像は検索リクエスト内でNova Liteへ渡し、S3や検索ログには保存しません。

両地域で既存の1,756品目のEmbedding索引を検索候補の取得に使います。中島地域では公式カレンダーに明記された79行の分別例・説明を優先し、共通索引から得た候補には中島地域のルールを適用します。松山・北条地域の分類や注意書きをそのまま中島の回答根拠にはしません。候補に入ることと分類を確定できることは別です。既存のAWS環境は、別途更新するまで旧バージョンのままです。

判定は素材・大きさ・製品/容器包装の区別などの分類原則を踏まえ、必要な場合のみ追加質問を1つ返します（`waste_guide_service.py`）。

## 構成

| パス | 内容 |
| --- | --- |
| `frontend/` | Flutterアプリ |
| `backend/` | FastAPI、Titan Embedding検索、分類処理 |
| `backend/evaluation/` | あいまい検索の評価パイプライン（データ生成・採点・比較） |
| `data/` | 自治体ごとの分別資料と地区別の収集カレンダー（[配置ガイド](docs/data.md)） |
| `infra/` | TerraformとAWS構成 |
| `scripts/` | 自治体データの生成・検証、パッケージ作成・AWS関連スクリプト |
| `docs/` | データ配置ガイド・実験レポートなどのドキュメント |

自治体の分別資料から作成したCSVと生成カレンダーはGitに含めていません。松山市の既存Embedding索引は追跡し、それ以外の自治体別NPZ索引はGit管理外で取得・生成します。バックエンドの再構築・再デプロイや精度評価を行う場合は、[`docs/data.md`](docs/data.md)に従って必要なデータを取得・生成してください。

バックエンドの自治体別データ読み込み形式は[複数自治体バックエンドのデータ契約](docs/multi-municipality-backend.md)を参照してください。標準カタログには上記20自治体を登録しています。Git管理外のCSV・NPZ・カレンダーが欠ける環境では、その自治体を別自治体のデータで代用せず、セットアップエラーとして扱います。

八幡浜市は20 PDFを23選択地区へ分けています。郷・中央（郷一木地区・旧道沿い）は紙類4区分だけ収集日未確認とし、ほかの収集日は利用できます。

## AWS環境の管理

Flutter Webは[S3＋CloudFrontで公開済み](https://d1up4ijatag29i.cloudfront.net)です。[手動更新手順](docs/aws-frontend-hosting.md)の`python3 scripts/frontend.py prepare`で最新mainの隔離ビルドとdry-runを行い、確認後に`deploy <実行フォルダ> --execute`で公開します。通常更新ではTerraformは不要です。ローカルのAWS CLI認証を使い、将来用の`workflow_dispatch`は保持しますが、mainへのpush・マージでAWSへ自動デプロイしません。

公開検索APIは認証不要で、Terraform定義ではAPI Gatewayの5 req/s・burst 10を設定しています。URLは公開情報であり、スロットリングは利用者別制限や請求額上限ではありません。[濫用対策の残作業](docs/public-repository-security.md#aws側の濫用費用対策別途承認後)を確認し、FlutterへAWS認証情報や分析キーを埋め込まないでください。検索文・AIの言い換え・追加質問と回答・AIの生成回答は品質改善用ログへ保存し、分析キーを持つ管理者だけが閲覧できます。画像本体は保存せず、CloudWatch向けのアプリログにも本文を重複出力しません。[保存内容・期間と利用者への案内](docs/public-repository-security.md#検索統計と個人情報)を参照してください。

```bash
# 構築・更新
./scripts/aws-up.sh

# 削除
./scripts/aws-down.sh
```

`aws-up.sh` はTerraformの適用と比較実験用Knowledge Baseの同期も行います。更新前にLambdaパッケージとTerraform planを確認してください。既存Lambdaのコードだけを更新する場合は、全20市町のZIPが直接アップロード制限を超えるため、[S3経由の更新・バックアップ・復旧手順](docs/lambda-s3-deploy.md)を使用してください。

AWS構成、費用、権限、ローカルBackendの起動方法は [`infra/README.md`](infra/README.md) を参照してください。

プロンプトと分類処理は `backend/app/services/waste_guide_service.py`、モデルや検索件数などの設定は `backend/app/config.py` にあります。

曖昧検索のデータセット生成と性能評価の手順は [`backend/evaluation/README.md`](backend/evaluation/README.md)、実験設定・結果・誤答分析は [`docs/experiments.md`](docs/experiments.md) を参照してください。
