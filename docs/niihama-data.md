# 新居浜市の2026年度データ

新居浜市（`38205`、版 `niihama-2026.1`）を共通の自治体データ基盤に追加します。適用期間は **2026-04-01～2027-03-31**。他年度の日付を繰り返しで補完しません。AWSへの反映・アプリ配布は別途必要です。

## 対応範囲と出典

- [2026年度ごみ収集カレンダー](https://www.city.niihama.lg.jp/soshiki/haiki/gomika.html)：A〜L、大島1・2、別子山の **15 PDF・15収集地区群**。公式町名表の116記載を保持します。町・丁目・番地・国道11号線の南北の条件を省略せず、カレンダー番号・収集曜日を地区選択名に表示しません。市街地と大島の「宮西町」は地域名で区別します。
- [ごみ分別大辞典](https://www.city.niihama.lg.jp/soshiki/haiki/pamphlet.html)：現行公開分冊の27〜46ページ **1,349行**と、ガイドの確認済み説明例15件、計 **1,364検索行**。重複した一般名称・材質違いの行を無理に統合しません。
- [大型ごみの出し方](https://www.city.niihama.lg.jp/soshiki/haiki/dasikata-oogata.html)：現行の申込方法・料金・搬出期限・施設搬入条件を確認します。

原本HTML/PDF27件のURL・SHA-256・取得日（2026-11-04）は `sources.json` に記録します。ガイドの現在の公開版は2026-02-19更新で、辞典のモバイルバッテリー行も既に有害ごみへ改訂されています。2026年1月の変更を古い不燃区分へ戻しません。

カレンダーページの裏面リンク見出しには令和7年度が残りますが、表面は令和8年度を明記し、裏面を翌年度も使う「保存版」と説明しています。裏面の分別・期限は現行ガイドと表面で照合し、裏面の前年度表記から日付は生成していません。

8定期収集区分は燃やす、不燃、布、プラ製容器包装、びん・缶、PET、古紙、有害です。辞典上のびんと缶の出し方は分けて案内し、収集日は同じ区分です。**市街地と大島は7時30分、別子山は9時まで**。3分別設定は同じ新居浜市専用CSV・索引を共有し、期限・地区別カレンダーを切り替えます。他自治体の根拠は使いません。

分類と収集方法を分け、大型ごみ・自己搬入・収集不可・市への相談には定期収集IDを与えません。これらの通知・iCalは生成しません。正しい日付を確認できない場合の既存の `unverified` 状態は維持していますが、新居浜市の15 PDFの定期区分に未照合の日時は残していません。

## 分別の条件と未確認事項

- 一般の30cm以下／超えの条件を保持します。取っ手を含む鍋・フライパン、普通のプラ製品と容器包装、PET本体と付属品、衣類の状態などを区別します。個別の例外（一升びん、菓子缶、蛍光灯等）を一般の寸法基準で上書きしません。
- `category_options` は本体の明示的な分岐だけを登録します。取り外した電池・金具の分類を本体へ転用しません。新しい任意設定 `size_threshold_cm: 30` により、寸法未回答なら追加質問へ戻します。根拠として採用していない携帯式マッサージ器の寸法条件を、自己搬入のマッサージチェアへ適用しません。
- 辞典見出しの画像内の※1〜4はレンダリングで確認し、該当行だけへ展開します。寸法・金属厚さ、切る／たたむ条件、自己解体、年間1トンの条件を保持します。
- ボタン電池・充電式電池は辞典で「有害」。ガイド13ページは店頭回収も案内しています。店頭回収の案内を「市の収集禁止」と読み替えず、端子絶縁と回収先案内を注記へ併記します。車・単車・船用バッテリーは収集しないものです。
- **180cmちょうどの大型ごみ**はガイドの「180cm以下」と現行Web案内の「180cm未満」が異なります。受付可能と断定せず市へ確認します。資料の矛盾を自動修正したことにはしません。

## 大型ごみと搬入

大型ごみは電話 `0897-31-5300`（開庁日9〜14時）又は公式電子申請から申込む有料戸別収集です。1回10点まで、次の申込は2か月後。確認はがきで指定された日時・場所を確認し、**1点200円の処理券**を貼り、午前9時までに出します。傘などは複数個を1点と数える例外があるため、申込時の案内を優先します。粗大ごみ画面の案内に料金を記載しますが、既存の品目一覧APIは個別料金を登録しておらず「料金未確認」と表示します。一般の収集日を申込日程へ転用しません。申込記録は従来どおり端末での手動管理です。

自己搬入は50kgまで500円、超過10kgごと100円。マッサージチェア等は品目別の台数・自己荷降ろし条件を確認します。家電リサイクル4品目は市施設でも受け入れません。施設の休業日、毎月29日以降の搬入制限、土石等の年間量制限も公式案内を確認してください。

## 原本照合の方法と限界

`scripts/niihama_pdf.py` で次を検査し、`calendar_reviews.json` / `item_reviews.json` にレビュー済み要約を固定します。

- 辞典20ページの罫線から1,349行を抽出し、罫線とは別に数えた分類文字列の件数・ページ別件数と比較。分類セルの描画画像の色も照合します。注記は文字レイヤーから保持し、共通画像凡例を目視で確認しました。全品目の注記を別OCRで独立に読み直した検査ではありません。
- カレンダー15 PDF、**全5,475日付**を印刷日付・曜日・月・位置・分類記号で検査し、別信号としてレンダリングした各日セルの色と照合。日曜の `24／31` 共用セル、8月の6段表示、年末年始、土日祝日・例外を含みます。生成JSON同士の一致だけを確認する検査ではありません。
- 大島の黄色※＝不燃＋布、緑※＝びん・缶＋PET＋古紙。別子山の緑※も同じ3資源区分。不燃と布は別日です。裏面の記号と色も見て対応を確認しました。
- `休` は休業、`●` は施設搬入のみ、`／` は収集なし。日付の丸印も施設搬入条件であり、それだけで通常収集を生成しません。これらと大型の申込制を区別します。
- 公式町名表と各PDFの対象地区枠も照合します。丁目範囲の「1・2・3」と「1〜3」、国道の「より南」と「以南」等の表記差は `areas.json` に明記します。

市による校閲や全日付の人手監査ではありません。原本変更時にはハッシュ又は抽出要約の不一致で停止し、確認なしに承認状態を更新しません。
