## 再取得・抽出（課金なし）

Python 3.12、バックエンドの依存関係、開発用PyMuPDF 2.0.0、画像検査用Pillowが必要です。移動前の仮想環境を使う場合も、実行ファイルの古いshebangを避けてPythonの `-m` で起動してください。

```bash
backend/.venv/bin/python scripts/uwajima_data.py fetch
backend/.venv/bin/python scripts/uwajima_data.py inspect
backend/.venv/bin/python -m pytest backend/tests/test_uwajima_data.py -q
```

`inspect` は `generated/item-review-candidate.json` と `generated/calendar-review-candidate.json` を作ります。候補を無条件に確認済みレビューへコピーしないでください。現在の `build` / `verify` は採用済みの `item_reviews.json`・`calendar_reviews.json` が必要で、未確定の現段階では実行できません。

描画OCRはmacOSのApple VisionとSwiftコンパイラで端末内処理します。有料APIは使いません。

```bash
backend/.venv/bin/python scripts/uwajima_image_audit.py --ocr
# 取得済みOCR・画像を再検査する場合
backend/.venv/bin/python scripts/uwajima_image_audit.py
```

別環境では、同じ原資料ハッシュに対応する `generated/renders/`、`generated/ocr/`、OCR manifest類も共有できます。`manual_image_reviews.json` は可視数字を確認した原資料ハッシュと日付を保持し、資料が変われば停止します。
